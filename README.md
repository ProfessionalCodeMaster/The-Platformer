# The Platformer
A 2D platformer made with Python and Pygame. 

This was made in the fall of 2014 during my second year in college.

I chose to make a platformer to further expand both my coding and game development skills.

I learned both game design, level design, and sprite animation through this project. I even learned parallax scrolling since this is a platformer.

## Rules
Move the main character known as "The Platformer" from left to right across a level and jump on platforms and avoid enemies and spikes along the way.

## Controls
Left Arrow - Move Left

Right Arrow - Move Right

Space Bar - Jump
